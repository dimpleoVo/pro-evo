# Methodology

Process-aware evaluation begins with an observable failure rather than only a final score. A diagnosis describes the failure mode in public-safe terms; an optimization target turns that diagnosis into an observable success condition. An intervention is assessed by observable behavior and public reverification, not by unpublished latent reasoning.

The evidence model separates result evidence (resolution/completion) from mechanism evidence (ordered target-linked chain). This allows a result to be reported with its attribution strength and limitations.
