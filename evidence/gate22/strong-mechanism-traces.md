# Gate22 public mechanism traces

Each of the three treatment branches exposes a sanitized, ordered public chain:

1. public failure;
2. process diagnosis;
3. pre-revision checkpoint;
4. same-checkpoint generic/treatment branching;
5. target-guided intervention;
6. observable behavior divergence;
7. post-treatment corrective revision;
8. public reverification and target resolution.

The projection contains event identities and observable statuses only. It does not include raw model responses, private reasoning, task source, hidden tests, expected patches, or evaluator implementation.
