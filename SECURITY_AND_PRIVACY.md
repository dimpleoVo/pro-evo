# Security and privacy

Publication follows default-deny allowlisting: only files authored for this clean-room staging release are present. Evidence is a structured public projection. The release excludes private paths, usernames, machine information, account information, credentials, raw provider responses, private reasoning, hidden-oracle material, benchmark/task source, expected patches, and company/internal artifacts.

The release audit runs deterministic secret, privacy/path, symlink, and binary-size checks. Its acceptance criteria require zero absolute private paths and zero symlinks into the private research repository.
